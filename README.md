# Midway Personal Loan Website

A personal loan landing page built with Next.js, React and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website.

## Pages

- `/` — Home page
- `/loan-calculator` — Personal loan EMI estimator
- `/about-us` — About Midway
- `/apply` — Application details and indicative loan charges
